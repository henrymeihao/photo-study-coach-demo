# AI Photography Coach · Demo

Read-only demo of [photo-study-coach](https://github.com/henrymeihao/photo-study-coach): pick a sample photo to see the analysis, annotations, light plan and A/B practice. The analyses were generated in advance; this page makes no model calls.

To coach your own photo, install the skill or paste the chat prompt from the main repo into a chat app that can read images.

Sample photos are from Unsplash under the Unsplash License; authors are credited on the page.
